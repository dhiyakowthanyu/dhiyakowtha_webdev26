## Overview
A personal portfolio website. Started as a midterm project and expanded for the final with Bootstrap 5, custom JavaScript, jQuery, accessibility features, and case study pages.

## Pages
- `index.html` - Home
- `work.html` - Projects
- `about.html` - About me
- `contact.html` - Contact form
- `adapt-case-study.html` - ADAPT Community Network full case study
- `coming-soon-goodreads.html` - Goodreads Redesign placeholder
- `coming-soon-healthcare.html` - Healthcare App placeholder

## Technologies Used
- HTML5 with semantic elements
- CSS3 with custom properties, flexbox, and grid
- JavaScript - Intersection Observer API, scroll reveal animations
- Bootstrap 5 - fully overridden with custom styles, no default colors or fonts
- jQuery 3.7 - reading progress bar, fade transitions, accordion interactions

## Accessibility Features
- Skip link on every page
- Alt text on all images
- `aria-label` on hamburger button
- `aria-expanded` on skills accordion
- Visible focus states for keyboard navigation
- Form labels linked to inputs with matching `for` and `id` attributes
- `lang="en"` on every HTML file
